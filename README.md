# BigBird Extension of the Bird Dev Dataset

BigBird is a component of the SKALPEL subsetting evaluation project (https://github.com/KyleLuoma/SKALPEL-subsetting-evaluation).

The database extensions are stored as SQL files in ```benchmarks/bigbird/bigbird_databases/generated_ddl```.
These .sql files can be executed over the corresponding bird dev .sqlite databases.

The NL Question - SQL query pairs are still valid for the BigBird versions of the Bird-SQL databases.

## Source Information
